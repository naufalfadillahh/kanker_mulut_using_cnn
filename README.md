# Klasifikasi Kanker Mulut dengan CNN

Repo awal untuk eksperimen model CNN klasifikasi citra sel rongga mulut (sel skuamosa normal vs karsinoma sel skuamosa).

Kode dan aplikasi web lengkapnya dipindahkan ke:

- **[sel_skuamosa](https://github.com/naufalfadillahh/sel_skuamosa)**: aplikasi web skripsi (Flask + TensorFlow/TFLite), demo live https://sel-skuamosa-naufal.vercel.app
- **[web_penulisan_ilmiah](https://github.com/naufalfadillahh/web_penulisan_ilmiah)**: versi awal untuk mata kuliah Penulisan Ilmiah
